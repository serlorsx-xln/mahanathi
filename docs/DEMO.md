# DEMO — มหานที (Mahanathi)

สคริปต์สาธิตสำหรับสัมภาษณ์ YWC21 (16:00, 2026-10-31). ทุกประโยคเป็นสิ่งที่ระบบทำได้จริงในเว็บที่ deploy แล้วเท่านั้น — ไม่มีสิ่งที่ยังไม่มีในหน้าเว็บ

## ก่อนเริ่ม (2 นาที)

- เปิด URL ที่ deploy ไว้บนโน้ตบุ๊ก (จอกว้าง) และสแกน QR code ด้วยมือถือตัวเอง
- ถ้าเปิดใน LINE ให้ชี้ให้กรรมการเห็นข้อความเสนอ "เปิดในเบราว์เซอร์ภายนอก" แล้วกดผ่าน — นี่คือ J6 ที่ทำงานจริง
- หน้าเริ่มต้นคือมุมมอง 3D TERRAIN: ภูมิประเทศไทยตอนกลางคืน เกจวัดน้ำ 804 สถานีทั่วประเทศเป็นเสาบาง ๆ ระดับสีตามสถานการณ์

## บทเปิด (3 บรรทัด พูดช้า ๆ)

> "มหานทีคือแผนที่ภูมิประเทศไทยตอนกลางคืน ที่มีเกจวัดน้ำของประเทศอยู่บนนั้นทุกตัว
> ข้อมูลเปิดจาก ThaiWater ของ HII และกรมชลประทาน — เราอ่านมาเล่าเป็นภาษาไทยที่คนทั่วไปฟังรู้เรื่องในประโยคเดียว
> ลองดูสถานีใกล้ตัวก่อนไหมครับ"

## จังหวะ 20 วินาที (QR + มือถือ)

1. กรรมการสแกน QR → หน้าเดิมโหลดบนมือถือ (เฟรมแรกตามงบ <2 วินาที)
2. กด **ใกล้ฉัน** → กล้องบินไปสถานีตัวอย่าง (สองพี่น้อง นครปฐม) → ประโยคเดียว: *"สูงกว่าตลิ่ง 0.86 เมตร (น้ำล้นตลิ่ง) ทรงตัว"* พร้อมตัวเลขที่วัดจริง เวลาที่วัด และที่มา
3. ชี้ที่ป้าย **· ตัวอย่างสถานี** และบอกตรง ๆ: "ตอนนี้ยังเป็นสถานีตัวอย่าง — รุ่นถัดไปใช้ตำแหน่งจริงบนเครื่องของผู้ใช้ ข้อมูลตำแหน่งไม่ออกจากเครื่อง"
4. สลับ **2D MAP / 3D TERRAIN** ให้ดู — แผนที่ราบกลางคืนกับภูมิประเทศ สลับกันได้ในไม่กี่วินาที

## ทำไมต้องมหานที (3 ข้อ)

- **ประโยคเดียวจบ** — สรุปภาพรวมประเทศเป็นภาษาไทยหนึ่งประโยค ไม่ต้องคลิกทีละสถานีอ่านตาราง
- **เกจทั้งประเทศบนภูมิประเทศจริง** — ระดับน้ำอ่านจากรูปทรงก่อนสี: เสามีขีดตลิ่ง น้ำเต็มเสาไหล ข้อมูลเก่าเป็นเสาโปร่ง ใช้ได้แม้ตาบอดสีหรือพิมพ์ขาวดำ
- **ทำงานตอนกลางคืนบนมือถือ แม้ใน LINE** — ดีไซน์มืดก่อน ปุ่มใหญ่พอสำหรับมือเดียว และมีทางออกให้ผู้ใช้ LINE จริง

## ความจริงที่ควรพูด (ความซื่อสัตย์ของผลิตภัณฑ์)

- ระบบทางการลึกกว่ามาก — เราอ่านข้อมูลเปิดของเขามาเล่าให้คนทั่วไปฟังในหนึ่งประโยค
- ของ 804 สถานี 315 สถานีมาจากกรมชลประทาน (RID) ผ่าน ThaiWater — ข้อมูลเปิดคือเหตุผลที่งานนี้เกิดได้
- เราบอกแต่สิ่งที่วัดได้: ระดับ ณ เวลาที่วัด จากผู้ให้ข้อมูล ไม่ทำนาย ไม่บอกว่าจะท่วมหรือไม่ท่วม
- ประวัติ 72 ชั่วโมงมีพร้อมใน API ของเราแล้ว (รูปแบบไบนารี MNTL, เอกสารที่ `docs/api.md`) — กราฟบนหน้าเว็บเป็นเฟสถัดไป

## สิ่งที่ห้ามพูด (กฎของโปรเจกต์ บังคับด้วยเทส)

- คำว่า ปลอดภัย / จะท่วม / ไม่ท่วม และทุกถ้อยคำที่ทำนายหรือปลอบใจ
- "โหลดเร็วกว่าวินาที" — งบจริงคือเฟรมแรก <2 วินาที พูดตามงบเท่านั้น
- เปรียบเทียบเชิงลบกับ ThaiWater — เรายืนบนข้อมูลของเขา น้ำเสียงคือ "สร้างบนข้อมูลเปิดของเขา" เสมอ

## ถ้าถูกถาม

- **ทำไมดีไซน์มืด?** — ผู้ใช้จริงคือคนที่กังวลน้ำตอนกลางคืน ถือมือถือหนึ่งมือ หน้าจอสว่างคือศัตรูของตาที่ปรับตัวกับความมืดแล้ว
- **ข้อมูลเก่าทำไม?** — บางสถานีรายงานช้า เราไม่ปลอมให้ดูสด: เสาโปร่ง ป้าย "ยังไม่อัปเดต" และประโยคบอกเวลาที่วัดจริงเสมอ
- **ความแม่นยำ?** — ไปป์ไลน์ตรวจกับ oracle 789/789 เรคคอร์ดตรงกัน และตัวเลขทุกตัวบนจอมาจากข้อมูลวัดจริงไม่ใช่ค่าปัด
